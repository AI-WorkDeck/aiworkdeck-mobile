用户于 2026-09-10 明确确认 Android 备案变更已通过（“安卓备案OK了”）。历史 `mobile-store-distribution.md` 记的是同一 `-13A` 下先加安卓、再加鸿蒙。总表 7.2 的 9 月 3 日“审核中”早于该确认，不能作为当前阻塞依据。
