## 页面行为

| 页面 | 展开横屏 | 竖屏／窄分屏 | 半折与连续性 |
| --- | --- | --- | --- |
| 项目／文件 | 浏览时项目与文件分栏；阅读时文件列表与预览分栏，避免三栏挤占正文 | 阅读全宽，按钮切回文件列表；可返回原目录 | 避开实际 reserved regions；同一预览控制器保持挂载，导航及采集覆盖层不重新下载 |
| 拍照／录像 | 左侧取景，右侧项目、快门、状态及最近采集 | 上方取景，下方控制 | 桌面半折上方取景、下方操作；录制对象与归档目标不随排版改变 |
| 录音 | 左侧录音操作，右侧项目材料 | 录音操作与材料上下排列 | 材料与控制避开折痕；恢复草稿沿用开始时的项目，停止保存期间仍保留该目标 |
| 资料库 | 左侧列表／缩略图，右侧选中记录；支持专注查看 | 单列列表或完整记录 | Native split view 的侧栏宽度跟随有效折叠区域；播放器不因排版重建 |
| 传输队列 | 左侧任务，右侧选中任务详情 | 全宽任务列表或详情，保留返回入口 | 选中任务保持；整行可点击 |
| 设置 | 左侧分类，右侧表单 | 全宽完整表单 | 大辅助字号回单列，内容可滚动 |
| 登录 | 表单居中且最大宽度 560 points | 保留可滚动表单 | 键盘与可达性沿用专门回归 |

布局按实际窗口、方向、字号和系统遮挡区域计算，不按设备型号硬编码“两块屏”。展开状态的尺寸与分屏窗口不是同一个条件。

## 环境与实际证据

- Xcode 27.1 / `27A9275`，iPhoneOS 27.1 / `24A94232`，macOS `26A434`。
- Duo 模拟器 `AWD Duo Oct24 Layout Audit`，iOS 27.1；使用 Device Hub 的实际 Open／Partially Open／Closed 和旋转操作，内屏截图为 2007×2853 或 2853×2007。
- `XCUIDevice.orientation` 在本机 Duo runtime 不改变实际姿态；`XCUIScreen.main` 也可能捕获未激活的外屏黑图。因此 XCTest 的通用旋转不计作 Duo 折叠证明。普通 iPhone 继续运行旋转回归；Duo 原生姿态、分屏另行验收。
- 文件阅读已实际经过展开横屏、竖屏、书本半折、桌面半折、Safari／WorkDeck 双 App 分屏、合上外屏及返回。目录、选择与预览保留，未再次要求下载确认。传输使用 DEBUG 合成服务，不计真实计费／生产桌面闭环。
- 资料库曾实测发现竖屏空白详情占半屏，以及书本半折侧栏未对齐折痕，均修复并在实际姿态下重验。资料库选中照片转竖屏、再回横屏仍为同一记录。
- 采集页横屏、竖屏、书本半折、桌面半折已视觉检查；使用截图夹具的画面仅证明排版，不证明镜头、声音或录制连续性。
- 队列在书本半折选中任务后转桌面半折仍显示同一详情。设置在书本半折正确分栏；最大辅助字号下单列可滚动。

## 正式签名与上传边界

本地 `beta/release` 改用原位 P12 与口令文件，创建随机口令的临时钥匙串，只配置本次签名，结束或异常时移除自己的条目。默认钥匙串保持不变，其他任务添加的条目保留。构建号从全 App 的 builds 与 buildUploads 读取，仍须串行发布。

实际调用 `build_local_ipa(1)` 完成归档、导出和 IPA 门禁；App、LiveActivity、Watch 严格签名校验通过。主 App／扩展实际 SDK 为 27.1，Watch 为 27.0。主任务再次读取 IPA 元数据并运行门禁通过。证据为 `/tmp/duo-local-helper-validation/result.json`，SHA-256 `e05f3d6299c7d525c019844cf12207740b5f61f240a5dbe604b442c1b6b98357`。

该 build 1 只是工具链验证，未上传，不可作为最终候选。最终包必须来自合并后的源码、使用重新分配的构建号并再次验证；旧 SDK 的 build 35／36 不作为本次发布候选。

## 真机验收边界

已连接用户 Duo，开启开发者模式，安装独立包 `WorkDeck Duo QA`，与 App Store 原版分开。QA 临时工程省略 Watch，仅用于手机测试；正式工程保留 Watch。

首轮 Device Hub 屏幕交互中拍照产生记录、录像计时运行，但画面为空。这不是有效传感器验收：[Apple 官方说明](https://developer.apple.com/documentation/xcode/interacting-with-your-app-in-device-hub)指出交互期间真机相机与麦克风不可用，可能录得空画面或静音。已停止该轮录像并退出 Device Hub，改由用户直接在手机上拍照、录像、录音及物理折叠，再核验实际文件。首轮空内容不得混入通过证据。

2026-10-25 用户在本会话回答上述直接真机验收询问：“已测试，都正常”。可据此确认用户反馈的拍照、录像、录音、横竖屏、半折与合上再展开路径；不据此扩展为用户未明确回答的来电、锁屏或长时间后台录制测试。复查时设备已不可连接，未独立读取这轮实际媒体文件。
